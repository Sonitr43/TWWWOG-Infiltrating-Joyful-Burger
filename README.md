# TWWWOG: Infiltrating Joyful Burger
A 2D platformer based on The Wonderfully Weird World of Gumball made for a school project.

![Infiltrating Joyful Burger logo](icon_full.png)

**Full credits can be found inside the game.**

![Screenshot 1](https://github.com/Sonitr43/TWWWOG-Infiltrating-Joyful-Burger/blob/df813dfe693453b4d951373c993003ec81b4091a/screenshots/Screenshot%201.png)

# Features:
- A tutorial + 3 levels
- 2 playable charcters: Gumball and Darwin, each with an unique ability
- 3 enemies
- Original pixel-art made specifically for the game
- Translations for English, Spanish and Catalan
