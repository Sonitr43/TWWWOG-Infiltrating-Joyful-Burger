# TWWWOG: Infiltrating Joyful Burger
 A "The Wonderfully Weird World of Gumball" fan-game made for a school project.

<ins>(NOTICE: For now the game is only in **catalan**. It'll eventually get translated to English and Spanish.)</ins>

# Features:
- Tutorial + 3 levels
- 2 playable charcters: Gumball and Darwin, each with an unique ability
- 3 enemies
- Original pixel-art made specifically for the game
